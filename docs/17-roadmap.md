# Roadmap

Roadmap is outcome-based; dates are assigned after team/capacity estimation.

## Phase 0 — Documentation approval

Approve this Bible, resolve launch placeholders, record ADRs, define success baselines. Exit: owner approval; no code before this gate.

## Phase 1 — Foundation

Next.js/Supabase environments, CI, i18n, design tokens, auth/verification, profiles/settings/consent, RLS baseline, logging/monitoring. Exit: secure bilingual shell and tested identity lifecycle.

## Phase 2 — AI build core

Gemini gateway, streaming, multimodal uploads, requirement schema, market evidence, normalized snapshots, deterministic compatibility rules, price breakdown, versioned builds. Exit: golden build scenarios meet safety/quality thresholds.

## Phase 3 — Build workspace

Saved builds, versioning, privacy/share, unlimited comparison, metrics, AI comparison toggle, collaboration/Realtimes, search. Exit: end-to-end research-to-share workflow.

## Phase 4 — Community and moderation

Language sections, forum/showcases, comments/likes/bookmarks, translation, notifications, reports, strikes/timeouts/bans/appeals, super-admin. Exit: moderation drills and accessibility acceptance.

## Phase 5 — Monetization and beta hardening

Free rolling quota, Stripe Pro/trial/refund/portal, fair-use controls, analytics, legal content, backup/restore, security and load tests, SEO. Exit: public-beta readiness review.

## Phase 6 — Public beta iteration

Measure validated-build completion, incompatibility escape, citations, latency/cost, moderation, conversion/refunds, and user feedback. Fix trust/safety before growth features.

## Later horizons

Historical prices/alerts, more regions/currencies/languages, retailer feeds, reputation/badges/moderator roles, richer upgrade simulation, annual/team tiers, dedicated search, mobile/PWA enhancements. Laptops remain excluded unless explicitly re-scoped by owner.

## Prioritization rule

Safety and correctness → task completion → clarity/accessibility → performance/reliability → growth/monetization → delight. A growth feature cannot ship by weakening compatibility, evidence, privacy, or moderation gates.
